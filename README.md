MARGARIDA — Oficina da Costura

O MARGARIDA — Oficina da Costura é um projeto web desenvolvido para apresentar os serviços de uma costureira, facilitando o contato com clientes e divulgando seu trabalho na internet. O site foi criado com o objetivo de fortalecer a presença digital do ateliê, tornando mais fácil conhecer os serviços oferecidos e solicitar agendamentos de forma prática.

O projeto busca oferecer uma interface simples, intuitiva e organizada, proporcionando uma experiência agradável aos visitantes e contribuindo para a divulgação do negócio.

Funcionalidades

Página inicial:

Apresentação da Oficina da Costura.

Identidade visual do negócio.

Divulgação dos serviços oferecidos.

Seção de serviços:

Apresentação dos serviços de costura.

Informações sobre reformas e ajustes de roupas.

Organização dos serviços para facilitar a consulta dos clientes.

Agendamento:

Formulário para solicitação de agendamentos.

Coleta das informações necessárias para o contato.

Integração com o WhatsApp para facilitar a comunicação com a costureira.

Seção de contato:

Informações para entrar em contato com a oficina.

Acesso facilitado ao WhatsApp.

Navegação entre as seções do site.

Navegação:

Menu com acesso às principais seções.

Rolagem até as áreas correspondentes da página.

Interface organizada para facilitar a utilização.

Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web:

HTML5 — estruturação do conteúdo e das seções do site.

CSS3 — estilização, identidade visual, layout e organização dos elementos.

JavaScript — implementação de interações e funcionalidades da página.

WhatsApp — integração para facilitar o contato e as solicitações de agendamento.

Como executar o projeto

Faça o download ou clone este repositório:

git clone https://github.com/Kamila0102/MARGARIDA-Oficina-da-Costura.git

Entre na pasta do projeto:

cd MARGARIDA-Oficina-da-Costura

Abra o arquivo index.html no navegador.

O site pode ser executado localmente em um navegador, sem a necessidade de instalar um servidor ou configurar um banco de dados, desde que as funcionalidades utilizadas não dependam de serviços externos.

Objetivo do projeto

O principal objetivo do MARGARIDA — Oficina da Costura é ajudar uma pequena profissional da área de costura a divulgar seus serviços e ampliar sua presença no ambiente digital.

Por meio do site, os clientes podem conhecer melhor o trabalho realizado, consultar os serviços disponíveis e entrar em contato de maneira mais rápida e acessível.

Além disso, o projeto demonstra como a tecnologia pode contribuir para a divulgação de pequenos negócios locais, tornando a comunicação com os clientes mais prática e fortalecendo a presença digital do empreendimento.
